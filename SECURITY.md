# Security Policy

## Supported release

This repository is an evolving project. No formal security support window or response-time guarantee is currently published.

## Reporting a vulnerability

Please do not publish exploit details, credentials, personal information, or a working attack in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use it. Otherwise, contact the repository maintainers privately through their GitHub profile and provide a concise description, impact, and reproduction steps.

Do not include real production secrets or customer data in reports. Rotate any credential that may have been exposed.
